# Crusaders-Game-Timeline
This is a timeline/archive of my previous work on "Crusaders" for anyone who's curious about the growth of the game's codebase.

## Note
While I was obsessively working on the game, I never implemented a formal version control system like Rojo; it was only a workflow I adopted retroactively after realizing I'd need to document my game-dev journey. Therefore, this repository exists to share the process that I went through to engineer the game as best as I could, from late May to late September (~4 months).
